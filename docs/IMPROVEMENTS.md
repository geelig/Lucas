# Lucas 2.1 改进清单

1. 终端行时间戳，可开关。
2. 修复远程文件名称、权限、大小和日期的对比度及列布局。
3. WindTerm 风格终端调色板，可选。
4. 文件面板支持左、右、底部停靠，可与连接管理器同在左侧。
5. 右侧资源管理器显示已连接终端、状态、地址、运行时间和录制状态。
6. 分组默认折叠，可配置。
7. 深色界面按 Apple 深色模式提高文本与背景对比度。
8. 导出使用系统保存窗口，成功后显示完整路径；可配置是否每次询问。
9. 文件面板默认跟随终端 cd 目录，可开关。
10. 按实际系统显示 macOS/Linux/Windows/网络设备/串口图标，可开关。
11. 密码使用 AES-GCM 加密；可配置是否保存密码，选择不保存时明确删除已存凭据。
12. 接入 ZMODEM 检测与接收，不能让 `**B00000000000000` 直接显示在终端；可开关。
13. 左键选择即复制、右键粘贴分别可配置。
14. 所有新增行为进入偏好设置，保存在本机。

## 约束

- 不读取或复用 EdgeTerm/LucasTerm 实现。
- 不用真实生产服务器测试；CWD、系统探测和 ZMODEM 用合成数据或本机进程。
- 加密不可降级成明文；配置只能控制是否保存，不能控制是否加密。

## Lucas 3.0.5 面板布局

1. 会话、文件管理器、资源管理器和历史命令均可通过左右栏各自的设置菜单显示、隐藏或移动。
2. 同侧模块合并为可横向滚动的页签，支持方向键、Home、End 和活动页签自动可见。
3. 左右栏默认宽度分别为 220 和 300，可整体拖动；底部文件面板与右侧栏互不影响。
4. 设置中心提供四个模块的独立显示和位置选项；旧默认宽度只迁移一次，不覆盖后续自定义。

## Lucas 3.0.6 数据与 Dock

1. Lucas 备份包含连接、分组、历史命令和常用命令，仍不包含密码或私钥口令。
2. 导入时合并本地历史与常用命令，按时间、命令和标识去重，不覆盖现有常用命令。
3. 文件选择器支持 `.lucas`；提供 Dock 快捷方式迁移脚本，只替换旧 LucasTerm 图标，不删除旧应用。

## Lucas 3.0.7 旧会话恢复

1. 修正更名时的旧配置目录兼容与迁移路径。
2. 提供受限恢复脚本：只恢复空连接库，保留旧目录，整体备份目标目录，并核对会话数和加密文件字节。

## Lucas 3.0.9 私钥与界面精修

1. SSH 私钥路径支持系统 Finder 文件选择，取消选择不会改变原路径。
2. 移除工作区重复的发送命令、文件和更多操作图标，保留分屏、搜索及右键标签管理。
3. 应用图标改用独立 `lucas.icns` 资源名并重新注册，避免 Dock 读取旧缓存。
4. 在不改变布局的前提下优化侧边栏、页签、资源卡片、菜单和状态栏；保留浅色主题与减少动态效果设置。
5. 修正应用图标三条滑杆的纵坐标和间距，旋钮左右错开且互不粘连。

## Lucas 3.1.0 文件表格与窗口体验

1. 使用 Wails 原生 `--wails-draggable` 属性，非全屏也可通过窗口空白区域拖动。
2. 文件页签所在侧栏最小宽度为 320，工具图标不再因过窄而收缩或隐藏；跟随目录仅显示图标并保留悬停说明。
3. 文件管理器改为名称、修改时间、类型、大小、权限、所有者、分组七列表格；支持整表横向滚动、固定表头及名称/时间/大小排序。
4. 统一工作区主要文字、辅助文字和控制按钮字号，资源数值保留清晰但适度的大小层级。

## Lucas 3.1.1 SSH 主机密钥变更

1. 密码错误与主机密钥变更分开处理；密钥变化时展示服务器地址和新 SHA256 指纹。
2. 只有用户明确确认可信后才更新对应 known_hosts 记录，拒绝时旧记录不变。
3. 更新采用原子替换并保留其他主机和注释，首次连接与密钥变更使用不同确认流程。

## Lucas 3.1.2 SSH 回调连通修复

1. 将密钥变更确认回调真正传入实际 `ssh.ClientConfig`，避免新版仍直接拒绝变更。
2. 新增真实客户端配置回归测试，覆盖旧记录、变更确认、接受后更新的完整路径。

## Lucas 3.1.3 会话双击连接

1. 会话列表和欢迎页最近连接改为双击打开，单击不再触发连接。
2. 右键编辑、打开会话及其他显式操作保持不变，连接提示同步标明双击。

## Lucas 3.1.4 会话定位与版本显示

1. 单击会话只选中并高亮定位，双击才建立连接，选中状态与已连接状态分开显示。
2. 左下角状态栏显示 Lucas 版本号，前端从 `wails.json` 的统一产品版本生成，避免与安装包不一致。

## Lucas 3.1.5 全命令配色与可靠双击

1. 新增通用终端语义配色：命令、参数、路径、URL、数字、字符串、关键字、JSON、日志级别、错误、警告、成功和次要信息。
2. 原始输出与 xterm 可见行统一着色，重置/白色控制码不再阻断配色；保留清屏、重绘和有意义的服务器颜色。
3. 外观编辑器支持全部新增颜色角色，浅色和深色主题均可配置。
4. 会话连接改为 400ms 内两次点击判定，移除整行拖拽干扰，仅系统图标负责拖动；Enter 可显式连接。
5. 重复连接时显示“正在连接，请稍候”，不再静默忽略。
